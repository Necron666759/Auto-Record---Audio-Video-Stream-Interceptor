# Auto-Record---Audio-Video-Stream-Interceptor
Automated recorder for Suno tracks and YouTube audio/video, captured through a dedicated, isolated Firefox instance so only that browser's sound (and screen, for video) is recorded. GUI + CLI, Linux (PulseAudio) and Windows (WASAPI) editions, auto-downloads ffmpeg/geckodriver, MP3/AAC/OGG/FLAC and MP4/MKV/WebM/AVI/MOV/FLV/3GP output.
